# Original browser survival game

Build a polished first-person cooperative survival game for desktop browsers. The world is an original abandoned alpine research station during a supernatural whiteout. Prioritize exceptional game feel, atmosphere, enemy behavior, environmental storytelling, spatial audio, controller and keyboard/mouse input, stable 60 fps on representative hardware, and a complete playable loop.

Use an original identity and properly licensed or generated assets. Compare the playable result against strong shipped survival games without copying protected content.
