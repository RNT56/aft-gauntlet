# Cross-platform research library

Build a macOS and Windows desktop application for collecting papers, webpages, annotations, PDFs, and project notes into local research libraries. It needs fast full-text search, drag and drop, keyboard-first navigation, multi-window support, file watching, exports, crash recovery, and optional encrypted sync.

The lead agent should choose native, Tauri, Electron, or another runtime from the actual requirements. Compare against excellent installed research and knowledge-management products.
